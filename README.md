<h2 align="center">Behind the code</h2>

<p align="center">
  I started with Discord bots in 2018. Since then, I've built for the web, mobile devices and a factory floor, and launched my own app on both app stores.<br />
  I like owning the whole product: the brand, the interface, the infrastructure and what happens after launch.
</p>

<details>
<summary><strong>The journey · 2018 to today</strong></summary>

<br />

|   Year   | Milestone                                                                                         |
| :------: | :------------------------------------------------------------------------------------------------ |
| **2018** | Built my first Discord bots. Continued building and maintaining them for clients until 2023.      |
| **2020** | Explored game development with C# and Unreal Blueprints.                                          |
| **2021** | Started building for the web with HTML, CSS and JavaScript.                                       |
| **2022** | Expanded freelance work into security reviews, firewall setup and DNS configuration.              |
| **2023** | Joined a wine company in Porto as a software developer.                                           |

| **2025** | Started developing OdoKeep.                                                                       |
| **2026** | 🚀 Launched OdoKeep on the App Store and Google Play.                                             |

</details>
